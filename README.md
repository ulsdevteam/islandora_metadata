### University Library System Digital Collections Metadata Management 
 
This repository contains scripts and files used for metadata management for University of Pittsburgh Library System collections. 
 
Metadata documentation, including information about the available templates, field definitions, and formatting guidance in the [Metadata Input Guidelines](https://docs.google.com/document/d/1Vk7XtENHWItiLV7BaJLhrSEhEzsQrv9dlBnUWQ1UYGw/edit?usp=sharing), managed by the ULS Metadata & Discovery Unit.
